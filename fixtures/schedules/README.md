# Supplied synthetic schedules

These two unmodified workbooks were supplied by Oil India in response to the team's SIH 26122 questions. They describe a conceptual garbage-treatment plant, not a live Oil India project. Retained as reproducible conformance fixtures for the authorized IntelliGrid implementation.

- `03-GWP_Construction_L4-L6_Schedule.xlsx`: 215 construction rows plus 11 L3 reference rows; 149 reporting leaves.
- `04-GWP_L3_Schedule.xlsx`: 84 L3 activities and eight phase rows. The 11 shared contractor L3 nodes are consolidated by Activity ID; all source references remain.

Combined: 318 source records, 307 unique nodes, 149 reportable activities. The parser preserves source row values and formula caches and never recalculates or rewrites these files. No official field-input answer key is included.
